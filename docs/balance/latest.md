# Balance tournament: latest run

Generated by `npm run balance` (tools/balance/run.ts). Do not edit by hand; rerun instead.

## Setup

- 43 start years (every year whose five seasons are all playable: 1973 to 2020, skipping those that would reach 1996), 6 seeds each (1, 2, 3, 4, 5, 6), five-season campaigns. 5394 campaigns and 2754 single seasons.
- Every bot reads the game only as a player can: the functions in `src/sim/view.ts` and `src/sim/advice.ts`, the market quote, the public campaign fields and the events the game reports. `tests/bots.test.ts` checks the bot source for the names of hidden state.
- Net worth is cash plus equipment at half its price. A farm is kept when it reaches the end of the fifth year without foreclosure. Marketable yield is the cwt per potato acre that came out of the ground graded saleable, before any storage shrink.
- Intervals are 95% bootstrap intervals that resample whole start years (seeds share their year's weather), 2000 resamples.
